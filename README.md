# ЭХО · Протокол «Аксиома»

Образовательная игра о создании искусственного интеллекта. Исследуйте сенсорный отсек станции, диагностируйте системы и проходите модули Академии.

## Запуск локально

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Перемещение по станции: WASD или стрелки, взаимодействие: E или нажатие на объект.

```sh
npx tsc --noEmit
npm run build
```

Прогресс хранится локально в браузере. GitHub Pages обновляется автоматически при изменениях в ветке `main`.
